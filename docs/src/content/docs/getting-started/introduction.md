nimap is a self-hosted, map-based application for documenting physical network infrastructure. It answers two questions: where exactly is a device, and which way does the cable to it run. It is built for one organization managing tens of buildings and hundreds to low thousands of devices.

Today nimap has:

- a map of locations and buildings with their outlines,
- a catalog of manufacturers and device models,
- an inventory of devices with short codes such as `SW-001`,
- file attachments, lifecycle statuses and user roles,
- sign-in with a password or through your OpenID Connect provider.

Floor plans, ports, VLANs and subnets, and cable routes are next.

To run your own instance, see [Installation](../../admin/installation/). To start using it, see the [User guide](../../user/overview/).
